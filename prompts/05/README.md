## 当前制作审查提示

- 5.1（晚饭小信使）的 Child 在 clip 间有一次离场/返回的省略，参考 Stage 1 4.2 的省略写法；书房内始终只有两个说话人。
- 5.3（打电话）采用**分屏双画格**构图：左格市场、右格家中车库，各自锁定机位，不交叉剪辑——这是 Stage 2 唯一的新构图，正式制作前应先试生成一课确认效果。
- 4.2（大风散步）的 Child 在 C 段穿上连帽衫并戴上帽子，是 Stage 2 唯一的穿衣动作；黄色 T 恤不更换，分镜已声明允许该脚本内的着装动作。
- 7.3（书架小工人）和 10.2（发条企鹅）是手部/道具连续性高危课，逐 clip 核对"谁的手、哪个方向、放在哪"后再试生成。
- 8.3（积木倒塌）的 Peer 情绪基线是"轻微失落、肩膀下垂"，属于有界情绪；生成时不得放大成哭泣。
- 导出器只拒绝危险或无边界的**正向**导演要求；固定负面安全句应保留。固定人物、眼神/手部动作、约十秒真实时长和镜头衔接仍需逐课试生成核对。文件齐全不等于视频完成。
