## 当前制作审查提示

- 1.2：原台词涉及三件衣服，镜头同时给出条纹红衣、恐龙红衣与蓝衣，避免“红色哪件”没有区别。
- 2.2、4.2、9.1：明确表现时间省略，不假装几秒内过完两分钟、完成如厕或行驶五分钟。
- 9.2 C：25 个词加取盒动作，须试读，必要时 12–15 秒；其他段也不能跳过试读。
- 固定人物、眼神/手部动作、声音和镜头衔接仍需试生成核对。文件齐全不等于视频完成。
