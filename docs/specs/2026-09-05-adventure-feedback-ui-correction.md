# 冒险地图顶部与成就反馈修正设计

> 日期：2026-09-05  
> 状态：已于 2026-09-05 书面与原生验收

## 1. 目标

在不改变“有无 performance 即完成”的二元规则下，修正顶部组件不对齐的问题，并恢复清晰的闯关目标感和完成成就感。视频回放仍是主奖励，星星只作为完成标记，不构成一至三星评分。

## 2. 顶部统一轨道

### 桌面与 Electron

- 顶部使用一条统一的 56px 视觉轨道。
- 左侧为品牌与 Stage，中央为真实进度，右侧为账户与 Electron 窗口控制。
- 品牌、进度和账户胶囊使用相同的 52px 外部高度、16px 圆角、边框和阴影基线。
- 桌面布局使用三列：左列左对齐、进度严格以窗口为中心、右列右对齐。Electron 窗口按钮属于右侧动作组，不能把进度推离中心。
- 所有可点击目标至少 44×44px；账户弹层限制在可用窗口高度内并独立纵向滚动，保证 800×600 下多用户列表仍可到达退出按钮。

### 手机

- 顶部保持单行，不换行；依次为紧凑品牌、`0/30`、头像。
- 三项共享同一垂直中心和 48–52px 高度，不因隐藏用户名或进度文字而改变位置。
- 在 390px 宽度下不得横向溢出；Stage 副标题可截断，但进度和头像不可压缩。

## 3. 二元但有成就感的关卡状态

### Locked

- 使用低饱和石质节点和明确锁标记。
- 节点仍可进入详情预习，但视觉上属于尚未抵达的目标。

### Current

- 使用青绿双环、定位旗或目标针、轻微抬高阴影和低频呼吸动画。
- 标题附近显示清晰的 `Current lesson` 目标标签。
- 只能有一个 current；它不代表完成，也不显示金星。

### Completed

- 节点主体优先显示 demo 缩略图，保持“自己的表演回放”是最终奖励。
- 节点外侧显示一颗金色星章，含义仅为“本关已完成”。没有一至三星等级，也不记录分数。
- 已走路径增加低饱和金色内线；未走路径保持象牙白和暖灰阴影。
- performance 保存成功后，本次页面会话中播放一次短促星章出现动画；刷新后不重复庆祝。

### Chapter completion

- 章节标题显示 `★ n/3`，替代中性的 `n/3`。
- 当一章从 2/3 变成 3/3 时，标题获得一次短促亮起效果；不弹出评分或阻断操作。

## 4. 动效与可访问性

- 动效只用于 current 呼吸、完成星章出现和章节完成亮起。
- `prefers-reduced-motion: reduce` 时关闭位移、缩放和闪烁，只保留静态状态差异。
- 状态不能只靠颜色表达：锁、目标针、星章必须具有不同形状；无障碍名称继续说明 locked/current/completed。

## 5. 数据与边界

- 不修改 scanner 的三态算法，不增加评分字段或数据库。
- 进度、章节计数和节点状态继续来自 `/api/library` 的真实 performance 数据。
- 不修改或删除 demo、recordings、用户资料和课程内容。

## 6. 验收

- 1440×960、800×600、390×844、844×390 无横向溢出。
- 桌面品牌、进度、账户三组高度一致且垂直中心一致；进度相对窗口居中。
- Electron 的账户与窗口按钮不会覆盖或挤偏进度，抽屉和账户弹层仍可点击。
- completed 节点有且只有一颗金色星章；current 没有金星；locked 有锁。
- 0/30、部分完成、整章完成和 30/30 四种状态均通过渲染测试。
- 保存 performance 后只出现一次非阻断庆祝；刷新不重复。

## 7. 验收记录

- 自动验收使用隔离的 Playwright/Edge 与真实 Electron/preload harness；本环境没有 Browser plugin，因此采用该已批准的回退路径。
- 1440×960、800×600、390×844、844×390 与 Electron 800×600 均验证无横向溢出、无页面错误或未解释的控制台错误。
- 移动端品牌标题可以在自己的紧凑列内省略；进度胶囊仍保持窗口居中，进度和头像不会被压缩。截图和完整命令记录保存在本次 SDD 任务报告中。
