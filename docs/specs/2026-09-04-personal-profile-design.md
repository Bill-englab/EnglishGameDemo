## 1. 目标与边界

让孩子在地图上认出自己的账号。只增加当前用户的头像、昵称和恢复默认头像；不增加社交主页、生日、性别、年龄评估、密码修改或管理员代改资料。

比较过三个范围：仅换头像最小但缺少友好的称呼；头像＋昵称满足个人识别需求；完整账户中心超出当前需要。采用已确认的中间方案。

登录用户名是稳定身份，只读显示。昵称不参与登录、文件路径、录像归属、课程解锁或 Stage 选择。现有用户没有资料文件时仍能登录，默认显示用户名和内置头像；管理员也可以编辑自己的资料。

## 2. 操作流程

右上角账号入口显示头像，点击后通过 My Profile 打开资料面板；已有用户管理、登出入口保留。桌面用紧凑对话框，手机用适配安全区的单列面板，沿用公共浮层的焦点、Escape、遮罩和滚动规则，不叠加两个模态层。

面板包含：头像预览、Choose Photo、Use Default、昵称输入、只读用户名、Save 和 Cancel。昵称去掉首尾空白后允许 1–24 个 Unicode 码点，拒绝控制字符；留空表示恢复使用用户名。作为纯文本渲染，不能执行 HTML。

选择照片只更新草稿，保存后才更新顶部头像和昵称；取消、关闭不提交。保存时禁用重复提交，失败保留草稿和旧资料并提供重试。关闭面板释放图片预览资源。正在录制或倒计时时，不允许打开资料面板打断录制。

上传前展示居中裁切的圆形头像预览；不增加手动缩放、拖动裁切编辑器。手机支持系统文件/照片选择，不额外索取摄像头权限。

## 3. 图片处理

- 支持静态 JPEG、PNG、WebP；单张上限 5 MiB，解码像素上限 1600 万。文件类型由实际解码确定，不信任后缀或客户端 MIME。
- SVG、GIF、动画 WebP、HEIC、损坏图片和超限图片给出明确提示，不悄悄保存；HEIC 提示先导出 JPEG。手机不支持预览时保留可重新选图的错误状态。
- 服务端校正 EXIF 方向，居中裁成正方形，缩小到 256×256，透明区域铺暖白背景，重新编码 JPEG。客户端预览采用相同方向与裁切规则。
- 输出只保留新像素，不复制 EXIF、GPS、注释或其他源文件元数据；不保存上传原图。默认头像使用仓库内置素材，不请求外站。
- 采用独立图片处理模块和 Pillow 依赖，不复用视频压缩流程，也不依赖 ffmpeg。实施时确认兼容版本并加入运行依赖。

## 4. 数据与权限

资料存放于独立的 `profiles/<username>/`，与密码文件、课程和录像分开；允许用 `PROFILES_ROOT` 覆盖根目录。整个运行时资料目录忽略入 Git，不放到公开静态目录。

后端分离资料读取/校验/图片处理与 Flask 路由。当前用户身份只取登录 session，沿用并再次检查安全用户名；客户端不能指定其他用户名或目标路径。

- `GET /api/profile`：读取自己的昵称、显示名和头像地址，以及用于保存的 session 绑定 CSRF token；响应不缓存。
- `POST /api/profile`：保存自己的昵称，以及可选新图片或恢复默认头像操作；使用 multipart，整个请求限制 6 MiB，不更改视频上传的全局上限。新图片与恢复默认不能同时提交。请求必须验证 session 绑定的 CSRF token；未登录返回 401，无效 token 返回 403。
- `GET /api/profile/avatar`：仅返回当前用户已保存的头像，无自定义头像返回 404，由前端显示默认素材。响应采用私有、不存储缓存策略，避免同一浏览器换用户后沿用旧头像。
- `/api/me` 保留原有 username/isAdmin 字段，增加 displayName/avatarUrl；不暴露密码、服务器绝对路径或原始图片数据。

昵称与头像在全部验证通过后一次提交：先写好新图片，再原子替换引用它的资料文件。任何失败都保持旧资料可用，不出现昵称已更新但头像保存失败的半完成状态。头像采用服务器生成的文件名；成功提交后才清理被替换的头像。同一用户保存操作串行化，不能误删另一请求刚写入的头像。

资料缺失或损坏时回退默认显示，不阻断登录和地图；读取错误记录在服务端，不向页面显示内部路径。删除账号时同时清理该账号资料，避免同名新账号继承照片；这一清理不涉及其 performance 录像。退出和换账号时清掉前端资料状态，丢弃旧用户仍在途的响应。

## 5. 验收

- 老用户、管理员、普通用户都可打开资料；无资料时正常回退。
- 上传 → 预览 → 保存 → 顶部更新 → 刷新后保留；取消不更改服务器资料；恢复默认后昵称可保留。
- 验证 JPEG/PNG/WebP、旋转照片、透明图、损坏图、伪装类型、动画、超出字节/像素上限及元数据剥离；输出固定尺寸且可解码。
- 验证昵称长度、空白回退、中文/英文、控制字符与 HTML 纯文本显示。
- 验证未登录、CSRF、路径越界、跨用户读取/写入拒绝；用户切换没有头像串号；删除并重建同名账号无资料继承。
- 验证重复保存、存储失败和并发提交；旧资料不受失败影响。
- 验证手机/桌面键盘、触摸和浮层关闭；录制不被资料面板打断。
- 使用隔离用户与临时目录，不操作真实头像、密码或孩子录像。运行两套现有测试与新增资料测试。

## 6. 实现前自检

- 范围与用户确认一致；不扩展成账户中心。
- 稳定身份与显示资料分离，不重命名任何录像目录。
- 图片验证、方向、裁切、隐私、默认状态、提交失败和账号切换均有明确行为。
- 接入现有公共 UI，不单独创建一套视觉体系。
