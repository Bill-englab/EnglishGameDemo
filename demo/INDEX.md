## 使用方法

1. 用 Xftp / scp / FTP 连到服务器
2. 进入 `demo/` 目录
3. 找到对应的章节文件夹 → 关卡文件夹
4. 把 `demo.mp4` 拖进去
5. 刷新网页即可看到

> 文件名必须是 `demo.mp4`（或 `demo.webm`）。文件夹名和上面的路径完全一致。
