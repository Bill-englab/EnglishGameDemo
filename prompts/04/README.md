- 1.2 始终只有两件红上衣（条纹、恐龙）；Child 的黄色 T-shirt 在三段内不更换，选中的恐龙上衣只交到手中。
- 2.2 的两分钟是上限且孩子提前完成；4.2 和 5.2 分别用明确省略表示真实如厕返回与完整读完一本书；9.1 不使用省略，五分钟估计没有在片内流逝。
- 10.1 Part B 为 13 个词，是 90 段中唯一低于首选 14–19 词的段落，但仍在 12–20 硬范围且只有小幅空手回忆动作。
- 导出器只拒绝危险或无边界的**正向**导演要求；固定负面安全句和 `never ... extend the clip` 等禁令应保留。
- 固定人物、眼神/手部动作、声音、约十秒真实时长和镜头衔接仍需逐课试生成核对。文件齐全不等于视频完成。
